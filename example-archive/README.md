# Example archive

Fourteen files shaped like an independent advisory practice's back catalogue: 6 PDFs, 4 Word
documents, 4 notes.

**Everything here is fabricated.** Meridian Sovereign Investment Authority, Halvorsen Family
Office, Northwind Air and Aldgate Bank do not exist. No real client, person, engagement, fee
or outcome appears anywhere in it. It exists so the walkthrough has something honest to search.

`files/` is what gets indexed. `source-text/` is the plain text those files were generated
from, kept so the corpus can be regenerated or extended.

To regenerate `files/` from `source-text/` on macOS: `cupsfilter` for the PDFs, `pandoc` for
the Word documents, plain copy for the notes.
